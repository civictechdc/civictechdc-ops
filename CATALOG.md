# Resource catalog

The front door to Civic Tech DC's support library. Updated November 3, 2026.
Status describes the resource, not permission to perform an external action.
The resource itself contains its scope, sources, and approval requirements.

| Resource | Type | Status | Use it for |

## Adding and maintaining entries

Use the [resource guide](docs/RESOURCE-GUIDE.md). Add one row per canonical
resource or coherent resource set; do not list every file in a tool's test suite.
Review this catalog with the resource when its purpose, location, or status
changes. A stale entry is a reason to check, not a reason to assume permission.
