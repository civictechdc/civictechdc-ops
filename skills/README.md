# Skills

A skill is a reusable procedure for a bounded support task, with defined
inputs, outputs, limits, and a completion check. It can guide a human or an
assistant; it is not an assistant's identity or a grant of authority.

## Current material

- [Project steward](project-steward.md) — draft procedure for turning authorized
  project context into a small, human-reviewed next step.

These are portable task references, not installed agent plugins. There is no
automatic installation, activation, or runtime synchronization. Preserve the
human approval and privacy boundaries when adapting a resource to a specific
agent's skill format.

To contribute a skill, follow the [resource guide](../docs/RESOURCE-GUIDE.md)
and add its canonical path to [the catalog](../CATALOG.md).
