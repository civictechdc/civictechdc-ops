# Task brief — draft template

**Status:** draft. **Reviewed:** November 3, 2026.
**Maintaining role:** unassigned. **Provenance:** starter template for bounded
human/assistant support tasks; not an assignment or permission grant.

```text
Task / requested by an authorized role:
Desired outcome / intended audience:
Relevant library resources:
Authorized current inputs / source dates:
Scope / explicit non-goals:
Requested output / where it should be stored:
Acceptance criteria / checks:
Time or cost bounds, if agreed:
Privacy and access limits:
Allowed actions / actions requiring separate approval:
Reviewing role / review point, if agreed:
Open questions / when to stop and ask:
```

For an assistant task, distinguish “prepare a draft” from “publish/send/merge.”
Do not put credentials, private record links, or personal contact lists in a
public task. Unconfirmed limits or reviewers remain unknown, not assumed.
