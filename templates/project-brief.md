# Project brief — draft template

**Status:** draft. **Reviewed:** November 3, 2026.
**Maintaining role:** unassigned. **Provenance:** starter template for this
library, based on its working principles; not a completed project record.

Copy the structure below into an appropriate working location. Only publish a
completed brief here if its information is suitable for public sharing.

```text
Project / brief date / current state:
Problem and intended users:
Evidence of need / sources / check dates:
How affected people are involved:
Smallest useful milestone / completion criteria:
In scope / explicitly out of scope:
Capacity / people who have actually agreed to participate:
Dependencies / assumptions / open questions:
Privacy, accessibility, or other risks:
Maintenance / handoff expectations:
Decisions and approvals still needed:
Next review point / agreed maintaining role, if any:
```

Do not infer participation from an old roster, treat a prototype as an ongoing
service commitment, or include private participant details in a public brief.
